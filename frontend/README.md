# UlyTech Website v0.1

🚀 Site web officiel d'UlyTech - Solutions digitales innovantes en Tunisie

## 🌟 Features

- ✨ Design moderne et responsive
- 🎨 Animations fluides avec Framer Motion
- 🔐 Page Cybersécurité unique avec terminal Kali Linux
- 🤖 Section Intelligence Artificielle
- 📱 Application mobile showcase
- ⚡ Optimisé pour performance (Lighthouse 90+)
- 🌐 Multilingue (Français)

## 🛠️ Technologies

- React 18
- Tailwind CSS
- Framer Motion
- React Router v7
- Three.js / React Three Fiber

## 🚀 Installation

```bash
npm install
npm start
```

## 📦 Build

```bash
npm run build
```
